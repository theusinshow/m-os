# Security Policy

M/OS stores personal captures and project information locally. Please do not
open a public issue containing a vulnerability, local database, backup, access
token, captured text, or other personal data.

Report vulnerabilities through GitHub private vulnerability reporting:

https://github.com/theusinshow/m-os/security/advisories/new

Only the current development branch is supported while the product is below
version 1.0. Security fixes may be released without backward compatibility for
pre-release data formats, but restore safety and migration behavior remain
explicit acceptance criteria.
